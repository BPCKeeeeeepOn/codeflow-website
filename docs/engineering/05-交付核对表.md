## 本轮实测抓出并修复的真实缺陷

| 编号 | 现象 | 根因 | 修复 |
|---|---|---|---|
| WEB-01 | 构建后首页 CSS 完全失效（body 背景透明） | layout 用正则捕获组 `(.*?)` 不含 `</head>`，`replace` 落空 → 样式链接从未注入 | 改为捕获后显式拼接 `{{OG}}{{CANONICAL}}{{EXTRA_HEAD}}</head>` |
| WEB-02 | 首页社区轨道 7 张卡成孤儿、div 失衡 | token 化正则 `.*?</div>\s*</div>` 匹配到第一张卡就停 | 改为按整段替换；G08 守卫生效 |
| WEB-03 | 壳页无样式（正文裸 HTML） | 壳页绕过 layout 直接写入产物 | 生成器重构：主页面与壳页共用 `wrap()` |
| WEB-04 | 浅色主题导航项实测 2.79:1 | **测量假象**（CSS transition 未跑完），非真缺陷 | 复测禁用 transition 后 5.07:1 ✓ |
| WEB-05 | 主按钮 3.88:1 / 浅色小节标 3.47:1（不达 AA） | 品牌蓝 #2383e2 用作小字与按钮填充时对比度不足 | 新增 `--accent-ink`（浅色下沉）与 `--btn-fill` 两支令牌，产品主色不变 |
| WEB-06 | 390 档两处溢出（报告面板 165px、教程页 281px） | `.vip-grid` 无窄屏折叠；grid 项 min-width:auto；表格匿名 table 盒按 max-content 撑开 | 补折叠规则 + `minmax(0,1fr)` + 表格包 `.table-scroll` 滚动容器 |
| WEB-07 | FastAPI 全站 404 | catch-all 路由声明在 static mount 之前抢先匹配；且旧进程未重启 | mount 置后 + 404 异常处理器 + 杀进程重启 |
| WEB-08 | 教程卡带出竞品名 | 摘要直接抽取产品教程正文（含竞品名与内部代号） | 12 篇摘要**改为手写** |
| WEB-09 | 学习/教程正文 GitHub 外链会 404 | 主仓私有且 OSS 包不含 `learning/` 与 `docs/05-教程` | 改为**站内渲染**（P3 机制），不给死链 |
| WEB-10 | WEB-05 修复后 G15 转红（site.css `:root`=3） | 对比度令牌以追加块落在文件尾，形成第三个 `:root`，违反令牌单一来源约束 | 两支令牌并入既有深/浅主题块，尾部仅保留组件覆盖；`:root` 回到 2 |
