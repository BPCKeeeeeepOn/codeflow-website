## 1. 执行顺序与依赖

```
P1 工程化（地基，必须最先）
  → P2 内容页（依赖生成器与公共层）
      → P2 顺序: index 迁移 → 静态内容页(features/evidence/deploy/oss-hub/vip/about)
                → 数据驱动页(learn×5/agent-community/docs)
  → P3 文档中心（依赖 P2 的 learn-tutorials 卡与生成器钩子）
  → P4 SEO/体验（依赖全部页面存在；OG 图可与 P2 并行）
每阶段: 实现 → check_all → 浏览器验证 → commit
```

## 3. 今日排期（AI 节奏，墙钟约 5~6h）

| 时段 | 内容 | 里程碑门 |
