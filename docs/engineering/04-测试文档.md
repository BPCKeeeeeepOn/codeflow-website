## 3. 人工走查清单（E2E 之后的最后一道，10 分钟）

- [ ] 首页通读一遍：文案无 AI 腔、无错别字、主张句三行内
- [ ] 每页 description 读一遍：像人写的、不堆关键词
- [ ] 数字来源表 vs 页面抽查 5 个数字
- [ ] 移动端 390 档目视：可读、可点、无遮挡
- [ ] 404 页真实触达一次

## 4. 通过标准（Definition of Tested）

1. `check_all.py` **18/18 守卫全绿**；
2. E2E **12/12 通过**且截图归档；
3. 人工走查 5 项全勾；
4. 任何红线守卫（G09/G10/G12）失败 = **不得提交**，修内容而不是改守卫（与产品仓"词表只增不减"同一纪律）。
