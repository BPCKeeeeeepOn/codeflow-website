## 1. 总体架构

```
site/src/                       ← 源（人写/生成器读）
  layout.html                     骨架：<head>槽位 + nav + {{CONTENT}} + footer + 脚本引用
  partials/
    nav.html  footer.html        共享组件（生成器注入 + 当前页高亮）
  pages/                          每页内容片段（<main> 内部）
    index.html features.html evidence.html deploy.html
    learn.html learn-testops.html learn-sre.html learn-tutorials.html learn-interview.html
    agent-community.html oss-hub.html vip.html pricing.html open-source.html
    changelog.html docs.html about.html 404.html
  registry.py?                    ✗ 不用 py 嵌数据 → pages.json（slug/title/desc/og/nav组/构建钩子）

tools/                          ← 开发工具（Python 标准库，零依赖）
  build_pages.py                  生成器（见 §2）
  check_all.py                    测试总入口（跑 §04 全部守卫，退出码即结论）
  check_budget.py                 性能预算
  sensitive_scan.py               敏感/竞品/诚实标识扫描
  check_numbers.py                数字来源审计
  og_template.html                OG 图渲染模板（浏览器截图用）

site/                           ← 产物（提交入库，纯静态托管直用）
  *.html  404.html  robots.txt  sitemap.xml  llms.txt
  assets/site.css  assets/site.js  assets/vendor/marked.min.js  assets/og/*.png
```

**数据流**：`src/* + pages.json + 产品仓只读引用 → build_pages.py → site/*`。
**方向纪律**：改页面只改 `src/`，产物禁止手改（`--check` 守卫）；产品仓只读。

## 2. 核心机制设计

### 2.1 生成器 build_pages.py（FR-P1-3/4，全项目最关键一件）

```python
PAGES = json.load(site/src/pages.json)
# 每项: {slug, file, title, desc, og:{title,desc}, nav:"main|none", nav_group}
#       features:[{name, anchor, render:"..."}]  ← sitemap/导航/404 共用

流程:
  1. 读 layout.html → 替换 {{NAV}}（注入 nav partial，当前页 aria-current）
                    → 替换 {{FOOTER}}
                    → 替换 {{TITLE}}/{{DESC}}/{{CANONICAL}}/{{OG}}
  2. 读 pages/{slug}.html 内容片段 → 替换 {{CONTENT}}
  3. 页面级构建钩子（注册表声明，生成器执行）:
     - learn-*      : 扫 learning/ 目录 → 渲染文章卡列表（标题/一句话/阅读时长=字数/400/min/GitHub 链接）
     - agent-community : 解析 agent-community/skills/*.md frontmatter → 渲染技能卡
     - deploy       : 从产品仓 快速开始.md 抽取 ```bash 代码块 → 渲染命令面板
     - about        : 读产品仓 VERSION → 注入版本号
     - docs         : 列 docs/05-教程/*.md → 12 篇教程卡
  4. 生成 sitemap.xml（lastmod=今天）/ robots.txt / llms.txt / 404.html
  5. --check 模式: 重建 → 与磁盘 diff → 不一致 exit 1（防手改产物）
```

设计取舍：
- **产物入库**而非 CI 构建——静态托管零配置、回滚=git revert；
- **不用 Jinja2 等模板库**——`str.replace` 槽位足够，保持零依赖；
- **markdown 渲染只在 P3 教程页**用 marked.js（运行时渲染，浏览器端），构建期不做 md→html（教程正文量大，构建期渲染会让生成器复杂化；浏览器端渲染对 SEO 的损失用"教程也被 sitemap 收录 + 摘要在构建期静态化"折衷——**修订**：教程目录页构建期静态化卡片，正文页运行时渲染并带 `<noscript>` 提示跳转 GitHub）。

#### P3 教程正文页（FR-P3-3）

```
/docs/tutorials/{01..12}.html   构建期生成壳页（title/meta/目录侧栏），正文区:
  <div id="md-body" data-md="../assets/md/tutorials/NN.md">
  → site.js 检测 data-md → fetch + marked 渲染 + 目录提取（h2/h3）
  → <noscript> + 文首"原文在 GitHub"链接兜底
assets/md/tutorials/NN.md       构建器从产品仓拷贝（含图片相对路径一并拷贝）
```
设计取舍：正文 md 随产物分发（构建期拷贝），运行时渲染；相比构建期渲染省掉 md 解析依赖，相比外链保证离线可读。

#### P4 关键实现（FR-P4-1~6）

- **OG 图**：`tools/og_template.html`（1200×630，印刷品语言：双专色 + 故障时点竖线构图，字全 HTML 排版）→ 浏览器打开 → `tab.screenshot()` 1200×630 截图 → PNG 压缩检查 ≤150KB → `assets/og/og-home.png`。全站共用一张（页级 OG 只换 title/desc）。
- **JSON-LD**：构建器按页注入——首页 SoftwareApplication（name/applicationCategory=DeveloperTool/offers=AGPL-3.0）、FAQPage（首页 FAQ 原文）、Organization（logo=内联 SVG 的 data URI 不行，JSON-LD 用站内绝对路径占位 + 上线时换域名）。
- **llms.txt**：构建器生成（站点摘要/页清单/文档入口/一键部署命令），放 Agent 入口位。
- **对比度**：site.css 令牌已达标（muted 亮 5.1:1/暗 6.7:1），新增类沿用令牌；P4 用浏览器 getComputedStyle 抽测 8 组关键前景/背景对。
- **四档分辨率**：E2E 用浏览器 evaluate `scrollWidth>clientWidth` 断言，逐页跑。

## 4. 依赖与风险

| 风险 | 缓解 |
|---|---|
| 拆公共层引入视觉回归 | 拆分前后对拍截图（P1 验收第一步）；守卫 check_all 兜底 |
| 产品仓路径不可移植 | 所有产品仓引用经 `--product-root` 参数（默认 `../aiops-platform`），CI/他人机器可配 |
| 教程图片相对路径断链 | 构建器拷贝 `docs/05-教程/images/`（若被引用）并重写路径 |
| 外链 GitHub 文章 404（仓库未公开/路径变更） | 生成器只链接**已知存在**的路径；check_all 外链检查标记 TODO 不阻断 |
| 今日工时超支 | 03 计划按功能点排优先级，P2 的 learn-4 栏目可降级为"主页含栏目清单"（砍 3 页），不影响 P3/P4 |

| 2026-10-29 | v1.2 | **实施期技术决策记录（2026-10-29 用户指令：前后端框架都要用主流）**：
